La aplicación permite ingresar dos números, elegir una operación y consultar el resultado en otra pantalla. 
Cada pantalla combina un archivo XML para su diseño y una clase Java para su comportamiento.

OperacionesMath es una aplicación Android desarrollada en Java que permite sumar, restar, multiplicar y dividir dos números. 
Incluye validación de datos, manejo de errores y una segunda pantalla para mostrar el resultado y volver a calcular.
